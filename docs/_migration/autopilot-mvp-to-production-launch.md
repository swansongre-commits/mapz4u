## 3. 중요한 결정

- `[세션결정]` MVP는 `MODE=MIXED`, `EMBED_TIER=3`(TF-IDF char 2-4gram)으로 진행했습니다. 근거는 무인 재현성입니다.
- `[세션결정]` 운영 트랙은 저장소 루트를 건드리지 않고 `real/` 하위에서만 진행했습니다. MVP 산출물은 실험 기록이므로 보존한다는 `MAPZ_PRODUCTION.md` §0 원칙을 따랐습니다.
- `[세션결정]` 하드코딩 주제 금지: `real/scripts/common.py`의 `load_topics()`는 `topics_v1.json`이 없으면 명시적으로 에러를 냅니다. 조용한 하드코딩 대체를 원천 차단하려는 의도입니다.
- `[세션결정]` TourAPI는 구버전 KorService1 대신 **KorService2**를 사용합니다. KorService1은 HTTP 500을 반환해 폐기했습니다.
- `[세션결정]` 정보나루는 API가 아니라 **사용자가 내려받은 CSV 파일**을 입력으로 사용합니다(`real/data/raw/data4library/`, 연령대별 4파일). 파서는 `real/scripts/lib_corpus.py`입니다.
- `[세션결정]` Render 배포는 빌드 시 커밋된 `data/clean`에서 DB를 재생성합니다(외부 API 호출 0). Streamlit Cloud는 빌드 스텝이 없어 `real/db/mapz_real.db`를 저장소에 강제 커밋했습니다.
- `[세션결정]` 저장소를 Public으로 전환했습니다. Streamlit Community Cloud 무료 플랜의 "비공개 앱 1개" 제한 때문이며, 사용자 명시 동의를 받고 실행했습니다.
- `[세션결정]` 로고를 이원화했습니다. 큰 자리(헤더)는 그래피티 래스터 이미지, 작은 자리(파비콘)는 벡터 핀 마크를 씁니다. 그래피티는 축소 시 뭉개지기 때문입니다.
- `[세션결정]` 정적 파일에 캐시 버스팅 쿼리(`?v=`)를 도입했습니다. 현재 `style.css?v=9`, `logo-graffiti.png?v=3`, `logo.svg?v=2`입니다.

## 4. 설계 또는 구현 선택의 이유

- `[확인]` TF-IDF를 고른 이유는 BGE-M3나 MiniLM이 멀티 GB 다운로드를 요구해 무인 실행의 재현성을 해치기 때문입니다. MAPS 자산도 TF-IDF 계보라 정합성이 있었습니다.
- `[확인]` 12개 주제는 사람이 고른 목록이 아니라 실수요(실제 대출건수)와 연결성(실제 시설 수)의 2x2 교차 결과입니다. 그 결과 MVP가 하드코딩했던 공룡과 로봇이 상위 12위 밖으로 밀려났고, 이는 Phase 0.5의 존재 이유를 실증하는 사례로 기록되었습니다.
- `[확인]` 신선도 불변식은 `status='운영중' AND (period_end IS NULL OR period_end >= today)`입니다. 만료 정보 노출을 품질 제1지표로 본 기획 원칙을 코드에 고정한 것입니다.
- `[확인]` 직업 상세에서 연봉·전망을 제외한 것은 제품 헌장의 Layer B 변환 규칙(직업명을 동사 서술로, 지위 신호 제거) 때문입니다.
- `[확인]` 그래피티 로고의 흰 배경은 처음에 `mix-blend-mode: multiply`로 가렸다가, 이후 실제 투명화(누끼)로 대체했습니다. 투명 PNG가 된 뒤에는 blend를 제거했습니다.
- `[확인]` 누끼는 단순 밝기 임계값이 아니라 **테두리에서 연결된 밝은 영역만** 투명화하는 방식(scipy 연결요소 라벨링)을 썼습니다. 글자 안쪽의 흰 광택이 검정 아웃라인으로 분리되어 있어 보존되기 때문입니다.
- `[확인]` 주제 타일의 파스텔은 주제색 원본을 바꾸지 않고 CSS `color-mix`로 흰색과 섞어 렌더합니다. 주제관 히어로는 흰 글자를 얹으므로 원색 대비가 필요해 원본 색을 유지해야 했습니다.

## 5. 시도했지만 실패하거나 폐기한 접근

- `[확인]` KCISA(한국문화정보원 한눈에보는문화정보) 엔드포인트를 여러 형태로 시도했으나 403/404만 반환해 사용하지 못했습니다. TourAPI가 행사 데이터를 대체 커버합니다.
- `[확인]` TourAPI KorService1은 HTTP 500으로 폐기하고 KorService2로 교체했습니다.
- `[확인]` 정보나루 오픈 API는 세션 내내 `vitalizationErr`(미활성)라 파일 다운로드로 우회했습니다.

- `[확인]` SVG로 그래피티 로고를 그리려던 시도는 사용자가 "아무리 봐도 그냥 글자 변형 같다"고 평가해 폐기했습니다. 벡터로는 스프레이 질감·번짐·3D 음영을 낼 수 없다는 한계를 인정하고, 사용자가 외부 이미지 생성 AI로 만든 래스터 이미지를 받아 적용했습니다.
- `[확인]` 벡터 워드마크 시안들(경로형 Z, 솔리드 앰버 Z, 튀는 Z, 아웃라인 Z 등)은 아티팩트로 제시했으나 채택되지 않았습니다.
- `[확인]` Streamlit Cloud 배포는 성공했으나(`mapz4u.streamlit.app`), 위젯 스타일 한계 때문에 주력 자리에서 FastAPI + Render로 교체되었습니다.
- `[확인]` 초기 OSM 태깅에서 일반 박물관을 전부 `art`로 기본 분류했다가 358건이 오분류되어 규칙을 좁혔습니다.
- `[확인]` `collect_jobs.py`의 GEN 보강 루프가 무한 루프를 일으켜 프로세스가 멈춘 사고가 있었습니다. 후보 소진 시 패딩으로 빠져나가도록 수정했습니다.

- `[확인]` Streamlit 버전을 최신 디자인으로 동기화할지, 아니면 폐기하고 Render 단일 배포로 갈지 결정이 필요합니다.
- `[확인]` 정보나루 API가 활성화되면 파일 입력을 API 수집으로 전환해야 합니다(구조는 `refresh.py`에 준비되어 있습니다).
- `[확인]` 제휴 콘솔(`real/admin/admin_app.py`)은 아직 배포되지 않았습니다. 별도 서비스로 배포하려면 `MAPZ_ADMIN_PW` 설정과 외부 노출 차단 정책이 필요합니다.
- `[추정]` 사용자가 파스텔 방향을 언급했으므로, 버튼·히어로 등 나머지 요소의 파스텔 적용 범위를 추가로 조율할 여지가 있습니다. 다만 버튼은 흰 글자를 쓰므로 대비 확보가 제약입니다.
- `[현재상태불명]` 마지막 커밋(`18a8dea`) 이후 Render 재배포가 실제로 완료되어 사용자가 파스텔 타일을 확인했는지는 이 세션 기록만으로 확정할 수 없습니다.

## 8. 다음 작업자가 알아야 할 맥락

- `[확인]` 이 저장소에는 **두 개의 독립 트랙**이 있습니다. 루트는 MVP(검증 실험, 5개 하드코딩 주제, SEED 위주), `real/`은 운영버전(실데이터, 12개 자동추출 주제)입니다. `real/`은 루트 코드를 import하지 않고 복사로 시작한다는 원칙이 있습니다.
- `[확인]` 배포 대상은 `real/`입니다. `render.yaml`의 `rootDir: real`이 이를 고정합니다.
- `[확인]` 제품 헌장이 코드로 강제됩니다. 금지어 lint(`lint_forbidden.py`)가 렌더 텍스트에서 등급·백분위·또래·필독 등 12개 단어를 0건으로 요구하며, 실제로 "필독"이 부정문 안에 있었는데도 FAIL 처리된 전례가 있습니다. 문구를 고칠 때 반드시 lint를 다시 돌려야 합니다.
- `[확인]` 정적 파일을 바꾸면 `base.html`의 `?v=` 값을 올려야 합니다. 올리지 않으면 브라우저 캐시 때문에 반영이 안 됩니다. 실제로 이 문제로 "반영이 안 되는데"라는 상황이 한 번 발생했습니다.
- `[확인]` 커밋 누락 사고가 있었습니다. CSS만 커밋하고 `base.html`을 빠뜨려 헤더 태그라인이 한 줄로 보이는 현상이 있었습니다. 템플릿과 CSS를 함께 바꿨다면 둘 다 스테이징했는지 확인하는 것이 좋습니다.
- `[확인]` `.env`가 과거 커밋에 포함되어 있었고, `git filter-branch`로 전체 히스토리에서 제거했습니다. 현재 원격에 `.env`가 없고 키 문자열도 0건임을 검증했습니다. 저장소가 Public이므로 비밀값 재유입에 특히 주의해야 합니다.
- `[확인]` 데이터 재생성 경로: `real/data/clean/*.json`과 `topics_v1.json`이 커밋되어 있어, `build_linkage.py` + `build_db.py`만 돌리면 외부 API 없이 DB를 복원할 수 있습니다.
- `[확인]` `.claude/launch.json`에 로컬 실행 프로필 3개가 있습니다: `mapz-real`(8000), `mapz-mvp`(8001), `mapz-streamlit`(8502).
- `[확인]` 페르소나·디자인 리뷰 서브에이전트 4종이 `.claude/agents/`에 있으며, MVP 평가에 실제로 사용되어 학부모 페르소나가 "필터 칩이 작동하지 않는다"는 실기능 결함을 잡아낸 이력이 있습니다.

## 9. 현재 코드만 봐서는 알기 어려운 사용자 의도

- `[확인]` **`Z`는 kids를 뜻합니다.** 사용자가 명시적으로 "Z는 kids의 ds를 z로 변경한 것"이라고 설명했습니다. MAPZ는 MAPS(Major·Aptitude·Path System) + KIDS의 결합이며, 그래서 로고에서 Z만 다른 색(블루)으로 처리되어 있습니다. 이 규칙을 모르면 Z 색상 분리가 임의 장식으로 보입니다.
- `[확인]` 사용자는 **"AI가 만든 티"를 강하게 싫어합니다.** 주제 타일 상단의 5px 색상띠를 두고 "너무 AI로 만든 것 같다"고 지적해 제거했습니다. 템플릿 느낌의 장식은 피하는 편이 좋습니다.
- `[확인]` 사용자가 원한 비주얼 톤은 **힙합 스트릿 그래피티 + 파스텔 물방울**입니다. 버블 레터, 두꺼운 아웃라인, 드립, 스프레이 스플래터를 레퍼런스로 제시했습니다. 파스텔 물방울 타일은 이 로고 톤과 통일하려는 의도입니다.
- `[확인]` 무인 완주(AUTOPILOT) 자체가 **실험 목적**이었습니다. 최종 리포트의 "무인 실행 회고", 즉 사람이 개입했어야 할 뻔한 지점 목록이 이 실험의 실질 산출물로 규정되어 있습니다. 파이프라인을 단순 코드로만 보면 이 의도가 드러나지 않습니다.
- `[확인]` 운영버전 Phase 0.5의 목적은 단순 기능 추가가 아니라 **"API를 왜 받았는지"를 복원**하는 것이었습니다. 정보나루·공공데이터 키는 원래 "실제로 많이 찾는 것"을 찾아내려고 받은 것인데 MVP가 주제를 하드코딩해 그 목적을 쓰지 못했다는 문제의식에서 출발했습니다.
- `[확인]` 사용자는 `mapz4u`라는 URL 문자열에 애착이 있습니다. Streamlit 서브도메인, Render 서비스명, GitHub 저장소명 모두 `mapz4u`로 통일했습니다.
- `[추정]` 헤더 로고를 120px까지 키우고 태그라인을 옆에 붙인 것은 브랜드 각인을 우선한 선택으로 보입니다. 일반적인 웹 헤더 기준으로는 큰 편이며, 스크롤 시 상단바가 두꺼워지는 트레이드오프를 감수한 것으로 판단됩니다.
